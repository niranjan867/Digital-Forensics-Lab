## Steganography Analysis and Hidden Data Detection Using StegExpose

## 🎯 Aim

To analyze digital image evidence using the StegExpose command-line utility, evaluate statistical properties associated with steganography, detect potentially hidden data using a configurable threshold, and generate a structured CSV report for forensic documentation.

## 📚 Theory

StegExpose is a specialized steganalysis tool designed to detect statistical anomalies in digital images that may indicate the presence of hidden information.

Steganography is the practice of concealing information within another digital medium, such as an image. One common technique is Least Significant Bit (LSB) steganography, where information is hidden by modifying the least significant bits of image data.

StegExpose performs statistical analysis of image characteristics and produces numerical values that can be used to identify potentially suspicious images. These values can be compared against a configured detection threshold for forensic analysis.

The general analysis workflow is:

**Digital Image Evidence ➔ Statistical Analysis ➔ Score Calculation ➔ Threshold Evaluation ➔ CSV Report Generation**

The tool is intended for detection and analysis rather than for embedding or extracting hidden information.

## ⚙️ Procedure

### Step 1: Open the Command-Line Environment
Open Command Prompt or PowerShell on the forensic workstation. The command-line environment is used to execute Java and StegExpose commands.

### Step 2: Verify Java
Check whether the Java Runtime Environment is installed:
```text
java --version
```
The installed Java version should be displayed before proceeding with the StegExpose analysis.

### Step 3: Navigate to the Working Directory
Navigate to the directory containing the StegExpose Java executable:
```text
cd /d "<StegExpose working directory>"
```
Verify the available files:
```text
dir
```
The StegExpose `.jar` file should be present in the working directory.

### Step 4: Prepare the Evidence Directory
Create or identify a directory containing the digital image evidence to be analyzed. The directory may contain supported image formats such as `PNG`, `JPG`, `JPEG`, and `BMP`. The original evidence should be preserved and should not be modified before analysis.

### Step 5: Execute StegExpose
Execute the StegExpose Java application against the evidence directory:
```text
java -jar StegExpose.jar "<Evidence Directory>" default 0.2 report.csv
```
The parameters specify the evidence directory, analysis mode, statistical threshold, and output report. The exact command syntax may vary depending on the StegExpose version being used.

### Step 6: Verify the Generated Report
After the analysis is completed, verify that the CSV report has been generated:
```text
dir report.csv
```
The report should contain the analysis results generated by StegExpose.

### Step 7: Review the CSV Report
The generated report can be opened using Notepad:
```text
notepad report.csv
```
Alternatively, it can be opened using Microsoft Excel for easier tabular analysis. The report contains vital information such as file name, steganography threshold classification, statistical analysis values, Chi-square results, sample-pairs analysis, RS analysis, and the fusion score.

## ⚠️ Limitation

StegExpose performs statistical steganalysis and provides indicators of potentially hidden information. A statistical score or threshold classification should not by itself be considered conclusive proof of steganographic content.

Results may depend on the image format, image characteristics, amount of embedded data, steganographic technique, and analysis parameters. Further forensic examination may be required for images identified as potentially suspicious.
